✨ HTML-in-Canvas & WebGL Shader Architecture

This campaign uses the modern HTML-in-Canvas API (<canvas content="drawable"> and drawable child elements) paired with Three.js WebGL2 Shaders:

  • WebGL Shader Pipeline (apply-webgl-shaders): Each collector card is a semantic DOM <article drawable> element uploaded via gl.texElementSubImage2D into a pre-allocated gl.RGBA8 texture inside canvas.onpaint, then shaded with an animated gold-foil border, candlelight warmth, snow sparkles, and subtle parchment wave vertex displacement.
  • 3D Hit-Testing & Accessibility Sync (interactive-content-in-3d-scenes): Every frame computes the 3D Model-View-Projection DOMMatrix via computeCanvasTransform() and registers it with canvas.updateElementGeometry() so buttons and text selection remain natively interactive and accessible to screen readers.
  • Universal Browser Fallback: In browsers where Chrome 157’s native content="drawable" flag is not yet enabled, the engine automatically synthesizes live high-DPI WebGL shader textures for the 3D cards while projecting the interactive DOM controls in lockstep.
